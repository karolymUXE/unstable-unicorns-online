# 🔒 Política de Seguridad

Gracias por tomarte el tiempo de revisar o reportar un problema de seguridad en **Unstable Unicorns Online**.  
La seguridad es fundamental para garantizar una experiencia estable y confiable para todas las personas que utilicen o contribuyan al proyecto.

---

## 📬 Cómo reportar una vulnerabilidad

Si encuentras una vulnerabilidad, por favor repórtala enviando un mensaje a:

**Responsable:** Karolym Montiel  
**Correo (opcional):** <agregar si deseas>  

También puedes abrir un *Security Advisory* privado en GitHub si lo prefieres.

Por favor incluye:

- Descripción clara de la vulnerabilidad  
- Pasos para reproducirla  
- Impacto potencial  
- Cualquier posible solución o sugerencia  

⚠️ Por favor **no abras un issue público** para reportar vulnerabilidades sensibles.

---

## ⏱️ Tiempo estimado de respuesta

Intentaremos responder dentro de los siguientes tiempos:

- **Vulnerabilidades críticas:** 24–48 horas  
- **Vulnerabilidades altas:** 3–5 días  
- **Vulnerabilidades medias o bajas:** 5–10 días  

Esto puede variar dependiendo de la disponibilidad, pero haremos lo posible por mantener una comunicación constante.

---

## 🛠️ Cómo manejamos los reportes

1. Revisamos el reporte y confirmamos la vulnerabilidad  
2. Evaluamos su severidad  
3. Desarrollamos un parche o solución  
4. Publicamos un aviso de seguridad si es necesario  
5. Reconocemos al contribuidor (si lo desea)

---

## 🧪 Buenas prácticas para contribuir de forma segura

Para evitar introducir vulnerabilidades:

- No exponer información sensible en logs
- Evitar el uso de funciones inseguras o desactualizadas
- Validar siempre entradas provenientes de sockets o clientes
- Mantener dependencias actualizadas
- No usar claves, tokens o secretos dentro del código
- Seguir el principio de "mínimo privilegio"
- No exponer métodos internos del motor del juego que puedan romper reglas

---

## 🔄 Soporte de versiones

Este proyecto sigue el siguiente esquema:

- La última versión en **main** es la que recibe parches de seguridad
- No se garantiza soporte para forks o versiones modificadas
